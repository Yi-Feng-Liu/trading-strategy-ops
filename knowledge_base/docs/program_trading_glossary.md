# 程式交易詳細術語表

這份文件是 `program_trading_terms.md` 的延伸 glossary，用來快速查詢程式交易、回測、風控與策略評估常見術語。  
其中「簡易判斷標準」屬於經驗值，不能視為絕對規則；不同市場、週期、槓桿、交易成本、資金規模與策略類型，都會改變合理門檻。

## 如何使用這份術語表

- 想先理解整體脈絡：先看 `program_trading_terms.md`。
- 想查單一名詞：看本文件各分類表格。
- 想評估策略好壞：優先看「績效與風險指標」與「指標好壞簡易判斷」。
- 不要只用單一指標判斷策略，至少同時看報酬、回撤、穩定性、交易成本、樣本外表現與實盤可執行性。

## 市場資料與行情

| 英文術語 | 中文名稱 | 涵義 | 實務解讀 |
| --- | --- | --- | --- |
| OHLCV | 開高低收量 | Open、High、Low、Close、Volume。 | K 線策略最常用的基本資料。 |
| Tick Data | 逐筆資料 | 每筆成交或報價變化資料。 | 高頻、短線、精細回測會用到。 |
| Bid | 買價 | 市場上目前願意買進的最高價格。 | 賣出市價單通常會打到 Bid。 |
| Ask | 賣價 | 市場上目前願意賣出的最低價格。 | 買進市價單通常會打到 Ask。 |
| Spread | 買賣價差 | Ask 與 Bid 的差距。 | Spread 越大，交易成本越高。 |
| Mid Price | 中間價 | Bid 與 Ask 的平均。 | 常用於估算理論價格，但不一定可成交。 |
| Last Price | 最新成交價 | 最近一筆成交價格。 | 不一定等於現在可買可賣的價格。 |
| Volume | 成交量 | 一段時間內成交數量。 | 用來衡量市場活躍度。 |
| Turnover | 成交金額 | 成交價乘以成交量。 | 比成交量更能反映資金規模。 |
| Liquidity | 流動性 | 市場能否快速成交且不造成明顯價格衝擊。 | 流動性不足會增加滑價與容量限制。 |
| Order Book | 委託簿 | 買賣委託價格與數量的排列。 | 可觀察市場深度與短線供需。 |
| Market Depth | 市場深度 | 不同價位可成交的委託量。 | 深度越好，大單越不容易推動價格。 |
| VWAP | 成交量加權平均價 | 依成交量加權的平均價格。 | 常用於執行績效比較與機構下單。 |
| TWAP | 時間加權平均價 | 依時間平均拆單成交。 | 常用於降低大單對市場的衝擊。 |
| Adjusted Price | 還原價格 | 調整除權息、拆股等事件後的價格。 | 股票長期回測通常應使用還原價格。 |

## 策略邏輯

| 英文術語 | 中文名稱 | 涵義 | 實務解讀 |
| --- | --- | --- | --- |
| Strategy | 策略 | 定義資料、訊號、進出場、風控與部位規則。 | 應能被清楚回測與重現。 |
| Signal | 訊號 | 策略產生的買進、賣出、加碼、減碼或空手指令。 | 訊號本身不等於實際成交。 |
| Entry | 進場 | 建立新部位的條件。 | 需搭配資金控管與停損。 |
| Exit | 出場 | 平倉或離開部位的條件。 | 出場規則通常比進場更影響風險。 |
| Filter | 濾網 | 限制策略只在特定條件下交易。 | 可降低雜訊，但太多濾網容易過度擬合。 |
| Regime | 市場狀態 | 例如趨勢、盤整、高波動、低波動。 | 不同 regime 可能適合不同策略。 |
| Trend Following | 趨勢追蹤 | 順著趨勢方向交易。 | 常見特徵是勝率較低但單筆獲利較大。 |
| Momentum | 動能 | 買強賣弱或追蹤近期強勢標的。 | 需注意反轉與擁擠交易。 |
| Mean Reversion | 均值回歸 | 價格偏離平均後預期回歸。 | 在趨勢行情可能連續虧損。 |
| Breakout | 突破 | 價格突破區間、壓力或支撐後進場。 | 需處理假突破。 |
| Arbitrage | 套利 | 利用不同市場或商品間的錯價。 | 真套利通常容量有限且競爭激烈。 |
| Statistical Arbitrage | 統計套利 | 根據統計關係交易相對錯價。 | 需要監控關係是否失效。 |
| Pairs Trading | 配對交易 | 交易兩個高度相關標的間的價差。 | 常搭配共整合或 z-score。 |
| Market Neutral | 市場中性 | 降低整體市場方向影響。 | 不代表沒有風險，仍有模型與流動性風險。 |
| Event Driven | 事件驅動 | 根據財報、公告、除息、併購等事件交易。 | 需處理事件時間與資料可得性。 |

## 訂單與交易執行

| 英文術語 | 中文名稱 | 涵義 | 實務解讀 |
| --- | --- | --- | --- |
| Market Order | 市價單 | 以市場可成交價格立即交易。 | 成交率高，但滑價不確定。 |
| Limit Order | 限價單 | 指定可接受價格交易。 | 價格可控，但可能不成交。 |
| Stop Order | 停損/停利觸發單 | 價格到達條件後觸發委託。 | 實際成交價仍可能滑價。 |
| Fill | 成交 | 委託成功被撮合。 | 回測需區分訊號價與成交價。 |
| Partial Fill | 部分成交 | 委託只成交一部分。 | 大單或低流動性商品常見。 |
| Fill Rate | 成交率 | 委託成功成交的比例。 | 限價策略尤其需要觀察。 |
| Slippage | 滑價 | 理論成交價與實際成交價差異。 | 對高頻、短線、低流動性策略影響很大。 |
| Commission | 手續費 | 券商或交易所收取的費用。 | 高換手策略必須嚴格估算。 |
| Market Impact | 市場衝擊 | 下單本身造成價格移動。 | 資金規模變大後特別重要。 |
| Latency | 延遲 | 訊號、送單、成交回報之間的時間差。 | 高頻與突破策略較敏感。 |
| Queue Priority | 排隊優先權 | 限價單在同價格委託中的排序。 | 影響限價單實際成交機率。 |
| Order Rejection | 委託被拒 | 因資金、價格、風控或商品限制而失敗。 | 實盤系統需有錯誤處理。 |

## 回測與驗證

| 英文術語 | 中文名稱 | 涵義 | 實務解讀 |
| --- | --- | --- | --- |
| Backtest | 回測 | 用歷史資料模擬策略表現。 | 只能證明過去表現，不保證未來有效。 |
| In-sample | 樣本內 | 用於開發策略與調整參數的資料。 | 表現好不代表策略可靠。 |
| Out-of-sample | 樣本外 | 未參與開發的驗證資料。 | 更能檢查策略泛化能力。 |
| Walk-forward Analysis | 滾動式驗證 | 反覆用前段訓練、後段驗證。 | 適合檢查參數是否穩定。 |
| Paper Trading | 模擬交易 | 不用真錢跑實盤流程。 | 可驗證資料、訊號、下單流程。 |
| Live Trading | 實盤交易 | 用真實資金交易。 | 會遇到真實滑價、延遲、成交與心理壓力。 |
| Look-ahead Bias | 偷看未來 | 回測使用當時不可能知道的資料。 | 會嚴重高估績效。 |
| Survivorship Bias | 存活者偏差 | 只看仍存在的標的，忽略下市或失敗樣本。 | 股票池回測常見問題。 |
| Overfitting | 過度擬合 | 策略太貼合歷史雜訊。 | 樣本外通常明顯退化。 |
| Data Snooping | 資料探勘偏誤 | 大量測試後只挑最好結果。 | 需要保留真正獨立的驗證資料。 |
| Selection Bias | 選擇偏誤 | 樣本選取方式造成結論偏差。 | 例如只挑熱門標的回測。 |
| Parameter Sensitivity | 參數敏感度 | 策略對參數變化的敏感程度。 | 參數稍微改變就崩壞通常不穩健。 |
| Robustness | 穩健性 | 策略在不同期間、標的、成本假設下仍有效。 | 是策略能否實盤化的重要條件。 |

## 績效與風險指標

| 英文術語 | 中文名稱 | 涵義 | 實務解讀 |
| --- | --- | --- | --- |
| Total Return | 總報酬率 | 期末資金相對期初資金的成長。 | 不能單獨判斷策略好壞。 |
| CAGR | 年化複合成長率 | 把總報酬換算成年化複利。 | 適合比較不同期間長度的策略。 |
| Volatility | 波動率 | 報酬的標準差。 | 波動越大，資金曲線越不穩。 |
| Max Drawdown, MDD | 最大回撤 | 從資金高點跌到後續低點的最大跌幅。 | 衡量策略最痛虧損。 |
| Sharpe Ratio | 夏普比率 | 每承擔一單位總波動，得到多少超額報酬。 | 常用於比較風險調整後報酬。 |
| Sortino Ratio | 索提諾比率 | 每承擔一單位下行波動，得到多少超額報酬。 | 比 Sharpe 更重視虧損波動。 |
| Calmar Ratio | 卡瑪比率 | 年化報酬率除以最大回撤。 | 看報酬是否值得承受最大回撤。 |
| Information Ratio | 資訊比率 | 相對基準的超額報酬除以追蹤誤差。 | 常用於主動型策略。 |
| Omega Ratio | Omega 比率 | 有利報酬與不利報酬的比例。 | 可補充 Sharpe 對非常態報酬的不足。 |
| Profit Factor | 獲利因子 | 總獲利除以總虧損。 | 大於 1 才代表總獲利高於總虧損。 |
| Expectancy | 期望值 | 平均每筆交易預期賺虧。 | 大於 0 才有正期望。 |
| Win Rate | 勝率 | 獲利交易占全部交易的比例。 | 必須搭配賺賠比一起看。 |
| Payoff Ratio | 賺賠比 | 平均獲利除以平均虧損。 | 可解釋低勝率策略為何仍獲利。 |
| Alpha | 超額報酬 | 相對基準或模型解釋後多出的報酬。 | 可視為策略創造價值的一部分。 |
| Beta | 市場敏感度 | 策略對市場漲跌的敏感程度。 | Beta 高可能代表績效主要來自市場方向。 |
| Tracking Error | 追蹤誤差 | 策略與基準報酬差異的波動。 | 主動策略常用。 |

## 指標好壞簡易判斷

下表是粗略經驗值，用於快速判讀策略回測或實盤統計。真正評估時應同時檢查交易次數、樣本外表現、交易成本、資金容量與市場狀態。

| 指標 | 偏差 / 需注意 | 普通 / 可觀察 | 良好 | 優秀 |
| --- | --- | --- | --- | --- |
| Sharpe Ratio | `< 1`，風險調整後報酬偏弱；`< 0` 通常代表不如無風險利率。 | `1 - 2`，有觀察價值。 | `2 - 3`，表現良好。 | `> 3`，非常亮眼，但需檢查過度擬合與成本假設。 |
| Sortino Ratio | `< 1`，下行風險補償不足。 | `1 - 2`，可觀察。 | `2 - 3`，下行風險控制不錯。 | `> 3`，很強，但需確認樣本數與極端虧損。 |
| Calmar Ratio | `< 0.5`，報酬相對回撤偏差。 | `0.5 - 1`，可觀察。 | `1 - 3`，報酬與回撤比例合理。 | `> 3`，很強，但需確認 MDD 是否被低估。 |
| Profit Factor | `< 1`，總虧損大於總獲利。 | `1 - 1.3`，優勢偏薄，容易被成本吃掉。 | `1.3 - 2`，通常較健康。 | `> 2`，很強，但交易次數太少時可信度不足。 |
| Expectancy | `<= 0`，長期平均沒有優勢。 | 略高於 `0`，需確認成本後仍為正。 | 穩定正值，且不同期間仍成立。 | 正值高且樣本外穩定。 |
| Max Drawdown | `> 40%`，多數資金與心理承受度會很吃力。 | `20% - 40%`，需看報酬是否足以補償。 | `10% - 20%`，相對可控。 | `< 10%`，回撤控制佳，但仍需看報酬是否太低。 |
| CAGR | 低於定存、短債或基準且風險更高時偏差。 | 接近基準，可觀察。 | 明顯高於基準且 MDD 可接受。 | 高於基準、回撤可控、樣本外穩定。 |
| Volatility | 波動高但報酬沒有提高時偏差。 | 需搭配 Sharpe / Sortino。 | 報酬能補償波動。 | 波動受控且報酬穩定。 |
| Win Rate | 不能單獨判斷；高勝率也可能因單次大虧而失敗。 | 必須搭配 Payoff Ratio。 | 勝率與賺賠比共同支持正期望。 | 高勝率、高賺賠比且樣本外穩定。 |
| Payoff Ratio | `< 1` 時需要較高勝率支撐。 | `1` 左右，需看勝率。 | `> 1.5` 通常較有彈性。 | `> 2` 且交易次數足夠時較強。 |
| Alpha | 長期為負代表不如基準。 | 接近 0，可能只是跟隨市場。 | 穩定為正。 | 正值高、穩定且可解釋。 |
| Beta | 與策略目標不符時需注意。 | 需依策略定位解讀。 | Beta 符合策略設計。 | 在控制 Beta 後仍有正 Alpha。 |

### 指標公式速查

```text
Total Return = 期末資金 / 期初資金 - 1
```

```text
CAGR = (期末資金 / 期初資金) ^ (1 / 年數) - 1
```

```text
Max Drawdown = (資金曲線低點 / 先前資金曲線高點) - 1
```

```text
Sharpe Ratio = (策略報酬率 - 無風險利率) / 策略報酬率標準差
```

```text
Sortino Ratio = (策略報酬率 - 目標報酬率) / 下行標準差
```

```text
Calmar Ratio = CAGR / abs(Max Drawdown)
```

```text
Profit Factor = 總獲利 / 總虧損
```

```text
Expectancy = 勝率 * 平均獲利 - 敗率 * 平均虧損
```

```text
Payoff Ratio = 平均獲利 / 平均虧損
```

## 資金控管與風控

| 英文術語 | 中文名稱 | 涵義 | 實務解讀 |
| --- | --- | --- | --- |
| Position Sizing | 部位 sizing | 決定每次交易投入多少資金或口數。 | 對 MDD 與破產風險影響很大。 |
| Exposure | 曝險 | 資金暴露在市場、標的或因子上的比例。 | 曝險過高會放大系統性風險。 |
| Leverage | 槓桿 | 用較少本金控制較大部位。 | 放大獲利，也放大虧損與斷頭風險。 |
| Margin | 保證金 | 槓桿交易需存放的擔保資金。 | 期貨、選擇權、融資融券常見。 |
| Stop Loss | 停損 | 虧損達條件時出場。 | 可限制單筆損失，但可能遇到跳空或滑價。 |
| Take Profit | 停利 | 獲利達條件時出場。 | 需避免過早截斷趨勢。 |
| Risk per Trade | 單筆風險 | 每筆交易最多願意虧損的資金比例。 | 常用於控制連續虧損。 |
| Kelly Criterion | Kelly 公式 | 根據勝率與賺賠比估算理論最適下注比例。 | 實務常用半 Kelly 或更低，避免波動過大。 |
| VaR | 風險值 | 在特定信心水準下可能損失的金額。 | 無法充分描述尾端風險。 |
| CVaR | 條件風險值 | 超過 VaR 後的平均損失。 | 比 VaR 更重視極端虧損。 |
| Risk of Ruin | 破產風險 | 資金跌到無法繼續交易的機率。 | 高槓桿與負期望會使風險快速升高。 |
| Capacity | 策略容量 | 策略可承載的資金規模。 | 資金太大可能讓滑價與市場衝擊吞掉優勢。 |

## 投組管理

| 英文術語 | 中文名稱 | 涵義 | 實務解讀 |
| --- | --- | --- | --- |
| Portfolio | 投資組合 | 多個標的或策略的集合。 | 分散風險的基本單位。 |
| Diversification | 分散化 | 分散到不同標的、策略或風險來源。 | 分散有效性取決於相關性。 |
| Correlation | 相關係數 | 衡量兩個報酬序列同向變動程度。 | 高相關在壓力時可能一起下跌。 |
| Covariance | 共變異數 | 衡量兩個資產報酬共同變動。 | 投組風險計算常用。 |
| Rebalancing | 再平衡 | 把投組權重調回目標比例。 | 可控制風險，但會產生交易成本。 |
| Asset Allocation | 資產配置 | 分配資金到不同資產類別。 | 通常比單一進出場訊號更影響長期風險。 |
| Tracking Error | 追蹤誤差 | 投組與基準報酬差異的波動。 | 主動管理越強，通常越高。 |
| Drawdown Correlation | 回撤相關 | 不同策略在虧損期間是否同時回撤。 | 比一般相關更貼近風險控管。 |

## 統計與模型

| 英文術語 | 中文名稱 | 涵義 | 實務解讀 |
| --- | --- | --- | --- |
| Z-score | 標準分數 | 距離平均值幾個標準差。 | 均值回歸與配對交易常用。 |
| P-value | P 值 | 在虛無假設下觀察到結果的機率。 | 低 P 值不等於策略一定有效。 |
| T-stat | T 統計量 | 衡量估計值相對標準誤的大小。 | 常用於檢查因子或 alpha 是否顯著。 |
| Stationarity | 定態性 | 統計特性是否隨時間穩定。 | 價差模型常需要檢查。 |
| Cointegration | 共整合 | 非定態序列的線性組合可能是定態。 | 配對交易常見基礎。 |
| Autocorrelation | 自我相關 | 序列與自身落後值的相關性。 | 可用來觀察動能或均值回歸特性。 |
| Regression | 迴歸 | 建立變數間關係的統計模型。 | 可用於因子分析、風險歸因。 |
| Feature | 特徵 | 模型輸入變數。 | 機器學習策略需注意資料洩漏。 |
| Label | 標籤 | 模型要預測的目標。 | 標籤定義會直接影響策略行為。 |

## 期貨、選擇權與加密貨幣

| 英文術語 | 中文名稱 | 涵義 | 實務解讀 |
| --- | --- | --- | --- |

## 實務判斷總結

評估策略時，可以用下面的順序快速檢查：

```text
1. Expectancy 是否大於 0？
2. Profit Factor 是否明顯大於 1？
3. Max Drawdown 是否能承受？
4. Sharpe / Sortino 是否合理？
5. Calmar 是否顯示報酬值得承受回撤？
6. 樣本外、不同市場期間、不同成本假設是否仍有效？
7. 實盤成交、滑價、容量與延遲是否會吃掉優勢？
```

最簡化的原則：

```text
高報酬不是好策略的充分條件。
高勝率不是好策略的充分條件。
高 Sharpe 也不是好策略的充分條件。

好策略至少需要：
正期望值 + 可承受回撤 + 樣本外穩定 + 成本後仍獲利 + 實盤可執行。
```
