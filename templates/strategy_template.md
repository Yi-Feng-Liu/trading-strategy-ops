# 策略模板：{strategy_name}

本模板用於建立單一策略的標準紀錄。建議複製到對應策略資料夾後填寫，例如：

```text
consolidation/long/{strategy_name}/README.md
trend/short/{strategy_name}/README.md
```

填寫目標不是讓策略看起來完整，而是讓人與 AI agent 都能用一致欄位判斷：策略假設是否清楚、規則是否可回測、風險是否可控、是否具備上架條件。

## 2. 策略摘要

用 3 到 5 句話說明策略核心：

- 這個策略想捕捉什麼市場現象？
- 為什麼這個現象可能存在？
- 策略在哪種市場環境可能有效？
- 策略在哪種市場環境可能失效？

|  |  |  |  |

可考慮暫停或下架的情境：

- 實盤表現明顯低於回測或模擬交易。
- Max Drawdown 超過原本可承受範圍。
- 交易成本、滑價或流動性惡化。
- 市場結構改變，原策略假設失效。
- 樣本外表現持續退化。
- 資料來源或執行流程無法穩定維持。

## 12. AI Agent 檢查清單

AI agent 協助評估策略時，應至少回答：

- 策略分類是否清楚？
- 交易方向是否清楚？
- 策略假設是否可被驗證？
- 進場、出場、停損、停利是否明確？
- 是否有使用未來資料或不可得資料的風險？
- 回測是否納入交易成本與滑價？
- 交易次數是否足夠支撐結論？
- 樣本外表現是否與樣本內差距過大？
- 最大回撤是否超出可承受範圍？
- 策略是否可能因流動性或容量限制而無法實盤化？
- 上架、暫停與下架條件是否明確？
